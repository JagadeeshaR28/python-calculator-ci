# Python Calculator

A simple Python calculator application built to
learn GitHub Actions and Continuous Integration.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division by zero handling

## Requirements

- Python 3.11
- pip

## Installation

Install dependencies:

pip install -r requirements.txt

## Run Application

python main.py

## Run Unit Tests

pytest -v

## Run Code Quality Check

flake8 .
